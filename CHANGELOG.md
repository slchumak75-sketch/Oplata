# История изменений

(теги `vX.Y.Z`). Новые записи — в `Unreleased`, при релизе переименовать раздел в версию+дату.

## [Unreleased]

## [0.8.0] - 2026-10-21

Ускорение сборки и синхронизация ручного ввода в «Таблице» по запросу владельца после v0.7.0.
Тег `v0.8.0` собирает workflow `release.yml`.

### Изменено

- **Сборка ускорена и упрощена:** CI больше не дублирует запуск на push рабочей ветки и PR, не запускается на теги и отменяет устаревшие проверки. Один Linux-job выполняет gofmt/vet/test, кросс-компилирует и публикует тестовый `oplata.exe`; сверка Excel через openpyxl запускается только при релевантных изменениях. В Release тесты и нативная Windows-сборка идут параллельно, а ZIP и контрольные суммы готовятся на Linux.
- **Ручной ввод в ячейках «Таблицы» синхронизируется с отсрочкой:** дата ячейки по-прежнему является сроком оплаты. Для нового прихода и при ручной правке записи без даты поставки сервер рассчитывает `delivery_date` от срока по отсрочке поставщика с учётом рабочего календаря РБ (`calc.DeliveryDateForDueDate`), поэтому карточка поставщика, журнал и экспорт используют одну пару дат. Выбранный поставщик правой панели также синхронизируется с редактируемой ячейкой.

## [0.7.0] - 2026-10-21

Удаление УНП поставщиков и прямое редактирование «Таблицы» по запросу владельца после v0.6.0 (PR #9).
Тег `v0.7.0` собирает workflow `release.yml`.

### Изменено

- **«Таблица»: панель «Поставка» постоянно находится справа** и не скрывается до выбора поставщика. В ней осталась одна сумма уже с НДС, а кнопка теперь называется просто **«Приход»**. Новые поставки из панели больше не сохраняют разбивку без НДС/НДС (API и старые записи с разбивкой по-прежнему поддерживаются).
- **Ячейки «Таблицы» редактируются напрямую:** всплывающее окно операций дня удалено. Клик по ячейке «Приход» или «Оплата» открывает ввод в самой ячейке; Enter/потеря фокуса сохраняет, Esc отменяет, пустое значение очищает ячейку. Если в ячейке сумма нескольких операций, новая сумма применяется к итогу дня.

### Удалено

- **УНП у поставщиков везде:** поле убрано из GUI, API и файла данных. Схема данных повышена до **v4**; файлы v1–v3 мигрируют автоматически, старый `suppliers[].unp` отбрасывается при следующем сохранении. У покупателей УНП сохранён.

## [0.6.0] - 2026-10-21

Дальнейшее упрощение интерфейса по запросу владельца после v0.5.0 (PR #8).
Тег `v0.6.0` собирает workflow `release.yml`.

### Изменено

- **Убраны кнопки «＋ Приход» и «＋ Оплата»** из верхней плашки и карточки поставщика. Добавление и правка операций остались на вкладке «Таблица» (панель поставки и окно операций дня); быстрая оплата просроченного в «Сводке» и карточке сохранена.
- **Карточка поставщика упрощена до одной таблицы приходов** со столбцами «Дата поставки», «Срок оплаты», «Сумма», «Оплачено» и «Статус». Отдельная таблица оплат, столбцы «Осталось», «Документ», «Комментарий» и кнопки действий в строках из карточки убраны; API, файл данных и FIFO-расчёты не менялись.

## [0.5.0] - 2026-10-21

Правки интерфейса и удаление встроенных стартовых сумм Excel из программы
(запрос владельца после v0.4.0, PR #7). Тег `v0.5.0` собирает workflow `release.yml`.

### Изменено

- **Кнопки в строках убраны** там, где попросил владелец: журнал «Операции» — без «Изм.»/«Удал.», список «Поставщики» — без «Изм.», быстрого прихода и оплаты, таблица должников «Сводки» — без кнопок быстрого добавления. Правка операций по-прежнему доступна из карточки поставщика и окна операций дня, реквизиты поставщика — через «Карточку поставщика».
- **Термины интерфейса переименованы:** «Собств» → **«Приход»**, «Выплата» → **«Оплата»** (кнопки шапки, «Сводка», «Таблица», карточки, журнал, формы, отчёт импорта; также тип операции в CSV и листе «Операции» XLSX). Подписи главного листа Excel «Собств»/«Выплаты», формат файла данных и имена полей API не менялись — импорт и экспорт остаются совместимыми.
- **«Таблица»: поля с данными не закрашиваются.** Бежевые выходные/праздники и жёлтый «сегодня» остались только в шапке дат; ячейки сумм, строка «ВСЕГО» и выбранный поставщик имеют белый фон.

### Удалено

- **Встроенные стартовые данные Excel 2025 из `oplata.exe`:** удалены `pkg/store/seed.json`, его `//go:embed` и генератор `tools/excel2seed.py`. Первый запуск теперь всегда создаёт пустую базу; уже существующий `%AppData%\Oplata\data.json` обновлением программы не очищается. Исходный Excel можно при необходимости импортировать вручную на вкладке «Данные». Старый флаг `-no-seed` оставлен как игнорируемый no-op для совместимости ярлыков. CI сверяет Excel без seed: `tools/exportdemo` напрямую импортирует исходный файл и экспортирует результат для openpyxl-проверки.

## [0.4.0] - 2026-10-21

«Таблица» ровно на 7 дней (пн–вс) с полосой месяца и года; ввод поставки
по клику на поставщика (суммы без НДС/НДС, автоматический срок оплаты
с переносом на ближайший рабочий день РБ); схема данных v3 (PR #6).
Тег `v0.4.0` собирает workflow `release.yml`.

### Добавлено

- **Панель поставки на вкладке «Таблица»**: клик по поставщику открывает справа ввод
  поставки — дата поставки, сумма без НДС, сумма НДС и автоматически вычисляемая
  сумма с НДС. Сумма с НДС создаётся как «Собств» на срок «дата поставки + отсрочка
  поставщика»; если срок выпадает на выходной или праздничный день РБ, он сдвигается
  на ближайший следующий рабочий день, и таблица переходит на неделю этого срока.
- **Разбивка начислений по НДС в данных и API**: схема файла данных v3
  (`amount_excl_vat_cents`, `vat_cents`; файлы v1/v2 мигрируют автоматически),
  проверка «без НДС + НДС = сумма с НДС», отображение разбивки в журнале операций
  и карточке поставщика, экспорт в CSV и лист «Операции» XLSX.

### Изменено

- **«Таблица» показывает только 7 дней** одной недели (понедельник–воскресенье).
  Кнопки влево/вправо сразу перескакивают на соседнюю неделю; над датами верхняя
  полоса теперь содержит только месяц и год (подписи поставщика/задолженности —
  строкой ниже). Ранее загружались 12 недель с прокруткой-прилипанием.
- Срок оплаты, вычисляемый сервером из даты поставки и отсрочки, теперь переносится
  с нерабочего дня на ближайший следующий рабочий день по календарю РБ
  (`calc.NextWorkingDay`/`calc.PaymentDueDate`). Явно заданный вручную срок не меняется.

## [0.3.0] - 2026-10-21

Один вариант — `oplata.exe` (console- и Wails/desktop-варианты отброшены);
«Таблица» по неделям с бежевой подсветкой выходных и праздничных дней РБ
(PR #5). Тег `v0.3.0` собирает workflow `release.yml`.

### Изменено

- **Вкладка «Таблица» переработана по неделям** (запрос владельца):
  - отображаются недели с понедельника по воскресенье; над датами — заголовок месяца;
  - горизонтальная прокрутка идёт скачками кратно неделе (прилипание к понедельникам),
    кнопки «‹ Неделя»/«Неделя ›», «‹‹ Раньше»/«Позже ››» (±8 недель), «Сегодня» и переход по дате;
  - столбцы выходных и праздничных дней **по законодательству Республики Беларусь**
    подсвечены бежевым; название праздника — во всплывающей подсказке даты;
  - столбец B теперь показывает сумму за отображаемый диапазон («Задолженность за диапазон»),
    раньше — за год. API: `GET /api/matrix?from=&to=` (+ совместимый режим `?year=&month=`).

### Добавлено

- **Рабочий календарь РБ** `pkg/calc/holidays.go`: государственные праздники и праздничные
  дни (Указ № 157), Радуница вычисляется по православной Пасхе, переносы рабочих дней
  по постановлениям Совмина на 2025 (№ 839), 2026 (№ 397) и 2027 (№ 499) годы для пятидневки
  (рабочие субботы не подсвечиваются). Таблицу переносов дополнять при новых постановлениях.

### Удалено

- **Остальные варианты приложения** (решение владельца: «далее редактируем только
  oplata.exe»): `oplata-console.exe` больше не собирается; Wails/desktop-вариант
  (`oplata-desktop.exe`, модуль `desktop/`) удалён из репозитория, из CI и из релизов.
  В релиз теперь попадает только `oplata.exe` (+ zip и SHA256SUMS.txt). Файл данных
  не изменился — данные пользователей не затронуты.

## [0.2.0] - 2026-10-21

Карточки поставщика и покупателя: УНП, справочник покупателей, схема данных v2
(PR #3). Тег `v0.2.0` собирает workflow `release.yml`.

### Добавлено

- **Карточки поставщика и покупателя в синей шапке GUI** (кнопки «🏭 Карточка поставщика»
  и «🛒 Карточка покупателя»):
  - Поставщик: наименование, **УНП** (новое поле), отсрочка в днях, примечание, архив;
    кнопки «Добавить поставщика», «Удалить поставщика» (удаление по-прежнему защищено
    при наличии операций), переход к операциям и долгам. УНП также виден в списке
    поставщиков и в карточке поставщика с историей.
  - Покупатель: новый справочник (вкладка «Покупатели») — наименование, УНП, примечание;
    кнопки «Добавить покупателя», «Удалить покупателя». Операций с покупателями пока нет.
  - УНП нормализуется (без пробелов, верхний регистр), проверяется (9–15 букв/цифр)
    и не может дублироваться внутри своего справочника.
- **Схема данных v2** (`Supplier.UNP`, `DB.Buyers`): файлы v1 и резервные копии v1
  автоматически мигрируют при загрузке (`store.Decode`). Импорт Excel в режиме replace
  сохраняет справочник покупателей и переносит УНП поставщиков по наименованию
  (в Excel этих данных нет).
- API: `GET/POST /api/buyers`, `PUT/DELETE /api/buyers/{id}`; `unp` в запросах поставщиков;
  `counts.buyers` в bootstrap. Тесты на УНП, покупателей и миграцию.

## [0.1.0] - 2026-10-21

Первый публичный релиз (тег `v0.1.0`, собирается workflow `release.yml`).

### Добавлено

- **Приложение «Оплаты» на Go с HTML GUI** вместо таблицы `Оплаты Строймаркет.xlsx`
  (лист «2025»: 43 поставщика × 365 дат, пары колонок «Собств»/«Выплаты»; формат разобран в
  `docs/EXCEL_FORMAT.md`, итоги сверены до копейки: 837 334,34 − 811 579,42 = **25 754,92**).
- **Три варианта исполняемых файлов с общим ядром и файлом данных:**
  `oplata.exe` (локальный сервер + окно Edge `--app`/браузер, без консоли),
  `oplata-console.exe` (тот же сервер с консолью) и `oplata-desktop.exe`
  (окно Windows на Wails v2.17.0/WebView2, отдельный модуль `desktop/`).
- **Ядро только на стандартной библиотеке Go:** `model` (деньги — int64 копейки, даты ISO,
  валидация), `calc` (FIFO-погашение, просрочки, сводка, матрица, карточки), `store`
  (JSON-файл, атомарное сохранение, ротация резервных копий, встроенный seed),
  `excelio` (чтение/запись XLSX формата оригинала через `archive/zip`+`encoding/xml`),
  `server` (HTTP API на 127.0.0.1 с токеном запуска и проверкой Host/Origin),
  `webui` (офлайн GUI на чистом JS, встраивается через `//go:embed`).
- **Интерфейс на русском:** «Сводка» (задолженность/просрочка/сроки/обороты месяца),
  «Таблица» в раскладке Excel (клик по ячейке — операции дня), «Поставщики» и карточки
  (FIFO-статусы, график баланса, быстрая оплата просроченного), «Операции» (фильтры/поиск),
  «Данные» (импорт/экспорт Excel и CSV, бэкапы, настройки, сброс).
  Необязательные поля начисления: дата поставки + отсрочка (срок считается автоматически,
  правится вручную), № документа, комментарий; у поставщика — отсрочка по умолчанию и архив.
- **Стартовые данные:** `tools/excel2seed.py` генерирует `pkg/store/seed.json` из Excel 2025
  (43 поставщика, 438 начислений, 415 выплат); при первом запуске загружаются автоматически
  (флаг `-no-seed` отключает). Предупреждение об аномалии «Алваис 11.03.2025» (выплата со
  знаком «+» в исходной таблице) сохраняется в базу и показывается баннером — арифметика
  Excel при этом не меняется.
- **GitHub Actions:** `ci.yml` — тесты ядра на Linux + сборка обоих Windows-вариантов
  при каждом push/PR (артефакты); `release.yml` — по тегам `v*` создаёт GitHub Release
  (3 exe + zip + SHA256SUMS, версия вшивается из тега). Go 1.25, Wails v2.17.0.
- **Документация для продолжения любым агентом:** `AGENTS.md` (статус, правила, грабли),
  `docs/EXCEL_FORMAT.md`, `docs/DATA_MODEL.md` (схема, расчёты, API), `docs/BUILD.md`,
  пользовательский `README.md`.
- **Тесты:** расчёты FIFO/просрочек, сверка seed с итогами Excel, XLSX round-trip и фикстура
  в стиле оригинала (sharedStrings, формулы дней, «июню», выплата с плюсом), API
  (токен/Host-guard, CRUD, импорт-экспорт через HTTP).

### Исправлено (по пути к первому зелёному CI)

- Сборка desktop-варианта на Windows-раннере падала на gofmt из-за конвертации LF→CRLF
  при checkout — добавлен `.gitattributes` с `eol=lf` для всего текста.
- В CI добавлены диагностика окружения Wails в аннотациях и независимая проверка экспорта:
  сгенерированный XLSX открывается openpyxl и сверяется с итогами оригинала
  (`tools/exportdemo`, `tools/verify_export.py`).

### Примечания

- Данные по умолчанию: `%AppData%\Oplata\data.json` (+ `oplata.log`, `backups/`).
  Репозиторий публичный, а XLSX и seed содержат реальные суммы — в README добавлено
  предупреждение и способ собрать exe без встроенных данных.
- Локально в песочнице Go недоступен (CDN тулчейна блокируется), поэтому компиляция и
  тесты выполняются GitHub Actions; `desktop/go.sum` генерируется в CI (`go mod tidy`).
