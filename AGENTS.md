# AGENTS.md — контекст для ИИ-агентов и разработчиков

> Этот файл — точка входа. Прочитайте его целиком, прежде чем менять код.
> Задача: Windows-приложение на Go с HTML GUI вместо Excel-таблицы оплат поставщикам,
> автосборка на GitHub Actions, всё документировано для продолжения любым агентом.

## Что это за проект (1 абзац)

`Оплаты Строймаркет.xlsx` — годовой журнал: строки = поставщики, колонки = даты (365 пар
«Собств»/«Выплаты»). **«Собств» = сумма к оплате за поставленный товар; дата колонки =
срок оплаты с учётом отсрочки (не дата поставки!); «Выплаты» = сумма выплаты** (в Excel —
с минусом). В интерфейсе программы с v0.5.0 эти операции называются соответственно
**«Приход»** и **«Оплата»**; подписи главного листа XLSX ради совместимости не меняются.
Приложение воспроизводит эту модель, добавляя просчёт просрочек (FIFO), сводку,
карточки поставщиков, журнал операций, импорт/экспорт того же XLSX.

## Железные правила (не нарушать без обновления этого файла и доков)

1. **Деньги = int64 копейки** (`*_cents`) везде. Float допустим только на границе чтения XLSX
   (`model.FloatToCents`).
2. **Даты = строки `гггг-мм-дд`** (`model.Date`). `due_date` — это срок оплаты С УЧЁТОМ отсрочки.
3. **Корневой (и единственный) модуль — только stdlib.** Новая внешняя зависимость = отдельное
   обоснование + обновление BUILD.md. Внешних модулей в проекте больше нет (Wails удалён).
4. **Знаки:** в приложении выплата положительна (уменьшает долг); инверсия «как в Excel с минусом»
   существует только внутри `pkg/excelio` (и в отображении матрицы GUI).
5. **FIFO** погашения — только через `calc.Allocate`; не дублировать логику статусов во фронтенде/хендлерах.
6. Общие пакеты лежат в **`pkg/`** (исторически ради desktop-модуля) — не переносить в `internal/` без причины.
7. Тексты ошибок API и GUI — **на русском** (показываются пользователю). Идентификаторы кода — английский,
   комментарии — русский. Сообщения коммитов — по-русски, осмысленные.
8. Каждое изменение поведения: код + тесты + `CHANGELOG.md` (раздел Unreleased) + затронутые доки.
   Меняется формат JSON → `model.SchemaVersion`↑ + миграция + DATA_MODEL.md.
   Меняется трактовка Excel → EXCEL_FORMAT.md + фикстура в `excelio_test.go`.
9. **НЕ коммитить** файлы данных пользователей, `*.exe`, `dist/` (см. `.gitignore`).
   Репозиторий публичный: исходный XLSX уже содержит реальные данные (exe их больше
   не вшивает) — новых персональных/финансовых данных сверх существующих не добавлять.
10. Ветка работы арены: `arena/796032fe-oplata`. PR — из неё в `main`. Теги релизов ставит владелец.

## Как проверять свою работу

- Источник правды — **GitHub Actions** (локально в песочнице Arena Go недоступен: CDN бинарников
  заблокирован — проверялось 2026-10-21). Цикл: push → вкладка Actions (`gh run list`, `gh run view <id> --log-failed`)
  → исправить → push. На машине с Go: `gofmt -l cmd pkg desktop`, `go vet ./...`, `go test ./...`
  (в desktop: после `go mod tidy`).
- JS: `node --check pkg/webui/assets/app.js`.
- Регрессия по деньгам: `calc.Test*`, `excelio.TestRoundTrip/TestParseOriginalStyleFixture`,
  `server.TestImportExportRoundTripViaAPI`; итоги оригинала сверяет CI через `tools/exportdemo`
  (прямой `ParseXLSX` исходного файла) + `tools/verify_export.py`. Пустоту первого запуска
  фиксирует `store.TestOpenCreatesEmptyDB`.
- Ручная проверка GUI без Windows: `go run ./cmd/oplata -no-open` на Linux/macOS → `http://127.0.0.1:8765`
  (браузер откроется вручную; `xdg-open` подхватится сам без `-no-open`).

## Подводные камни (уже найденные — не наступать снова)

- **CRLF на Windows-раннерах:** без `.gitattributes` (`* text=auto eol=lf`) checkout на
  windows-latest конвертирует `.go` в CRLF, и gofmt помечает файлы неотформатированными
  (дифф «весь файл»). Не удалять `.gitattributes`. Бинарники (`*.png`, `*.xlsx`) помечены binary.
- **Логи Actions недоступны из песочницы Arena** (CDN результатов блокируется, `gh run view --log-failed`
  даёт EOF) — диагностику в workflow выводить в **аннотации** (`::error`/`::notice title=…`),
  они читаются через `gh run view` и API. Ошибки компиляции Go GitHub аннотирует сам.
- Локального Go в песочнице нет, но синтаксис и форматирование проверялись настоящим `go/format`,
  собранным в WASM (npm-пакет `@wasm-fmt/gofmt`): `format(src)` для каждого `.go`.
  Это проверка разбора/формата, НЕ типов — типы и тесты по-прежнему проверяет только CI.

- Excel: опечатка месяца **«июню»**; выплата с плюсом у «Алваис» 11.03.2025 (+117,38) —
  импорт сохраняет арифметику и предупреждает, НЕ исправляет; «ВСЕГО» суммирует с строки 5;
  у двух последних поставщиков формулы только до колонки CH; дни в начале года — формулы `=A2+1…`
  (читать кэшированный `<v>`, нет кэша — восстанавливать по порядку).
- XLSX-писатель специально примитивный (inlineStr, кэшированные значения формул проставляем сами,
  `fullCalcOnLoad=1`). Не «улучшать» без теста round-trip + открытия в настоящем Excel/LibreOffice.
- `pkg/server`: гостевой `Host` в тестах `httptest` — `example.com`, guard его режет; в тестах
  выставлен `AllowAnyHost=true` + отдельный тест guard.
- Windows GUI-сборка (`-H windowsgui`) не имеет консоли: все ошибки дублируются в `oplata.log`
  рядом с данными — сохранять это поведение в новых точках входа.
  Не удалять `replace` на `../` — без него desktop потянет ядро из сети/не соберётся в монорепо-стиле.
- **Seed возвращать нельзя** без прямого решения владельца: с v0.5.0 `pkg/store/seed.json`,
  его `//go:embed` и `tools/excel2seed.py` удалены. Первый запуск обязан создавать пустую базу;
  обновление exe не должно очищать уже существующий `%AppData%\Oplata\data.json`.
