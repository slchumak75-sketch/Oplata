# Оплаты поставщикам (Oplata)

Windows-приложение на Go с HTML-интерфейсом для учёта оплат поставщикам — замена таблицы
[`Оплаты Строймаркет.xlsx`](Оплаты%20Строймаркет.xlsx).

**Термины в интерфейсе программы:**

| Термин | Что значит |
|---|---|
| **Приход** | Сумма к оплате за поставленный товар. Дата записи — **срок оплаты с учётом отсрочки** (та же дата, что в шапке колонки Excel). |
| **Оплата** | Фактически оплаченная сумма и дата оплаты. |
| **Долг** | В ежедневных столбцах «Таблицы» — баланс поставщика после операций этого дня, включая долг до начала показанной недели. |
| **Задолженность** | Сумма всего «Прихода» минус сумма всех «Оплат» (столбец B в Excel). |
| **Просрочено** | Открытые (непогашенные) суммы, у которых срок оплаты уже прошёл. Оплаты погашают приходы по FIFO — сначала самые ранние по сроку. |

> В исходном Excel те же колонки называются **«Собств»** и **«Выплаты»**. Главный лист
> импорта/экспорта сохраняет эти исходные подписи для совместимости; в интерфейсе,
> CSV и листе «Операции» используются названия «Приход» и «Оплата».

## Программа (собирается автоматически на GitHub Actions)

По решению владельца от 2026-10-21 остался **единственный вариант** — `oplata.exe`
(консольный и Wails/desktop-варианты из релизов v0.1.0–v0.2.0 отброшены):
локальный сервер + интерфейс в окне Edge (режим приложения) или браузера
по умолчанию. Просто запустить, установка не нужна. Запуск с флагами
(`-addr`, `-data`, `-no-open`, `-portable`, `-version`) — из командной строки;
подробности и журнал — в файле `oplata.log` рядом с данными.

**Где скачать готовый exe:** страница **Releases** (релиз создаётся при пуше тега `v*`,
см. [docs/BUILD.md](docs/BUILD.md)) либо вкладка **Actions** → последний запуск CI →
Artifacts (`oplata-windows-amd64`).

## Первый запуск

1. Запустите `oplata.exe`. Откроется окно интерфейса.
2. При первом запуске программа сама создаст **пустой** файл данных
   `%AppData%\Oplata\data.json`: встроенных поставщиков и сумм из Excel в `oplata.exe` нет.
   Если файл данных от предыдущей версии уже существует, он будет открыт как обычно —
   само обновление программы существующие суммы не очищает.
3. Данные из Excel при необходимости загружаются вручную: вкладка **Данные** → импорт `.xlsx`.
   При импорте исходного файла 2025 года программа предупредит о записи с сомнительным знаком
   («Алваис», 11.03.2025 — в Excel оплата стоит с плюсом).

> ⚠️ **Репозиторий публичный**, а исходный Excel в нём содержит реальные суммы оплат.
> Сам `oplata.exe` эти суммы больше не встраивает. Если публичность исходного файла
> нежелательна — сделайте репозиторий приватным (Settings → General → Change visibility).

## Возможности

- **Сводка:** общая задолженность, просрочка, сроки на сегодня/неделю, обороты за месяц,
  таблица должников без кнопок в строках, списки просроченных и ближайших оплат,
  быстрая кнопка «Оплатить» в списке просроченных.
- **Поставщики:** недельная таблица ровно на 7 дней с понедельника по воскресенье и на
  всю ширину экрана без горизонтальной прокрутки. Сверху над датами — полоса месяца
  и года; кнопки влево/вправо перескакивают сразу на соседнюю неделю.
  В шапке дат бежевым отмечены субботы, воскресенья и праздники, добавленные вручную
  на вкладке «Данные» (название праздника — по наведению курсора на дату); поля с суммами не закрашиваются.
  Поставщики × 7 дней: слева — «Просрочено» (на сегодня) и сумма «за неделю»,
  на каждый день — «Приход» · «Долг» · «Оплата», строка «ВСЕГО». Клик по наименованию
  поставщика открывает всплывающую форму «Поставка»: дата поставки и одна сумма с НДС;
  кнопка «Приход» создаёт начисление на срок «дата поставки + отсрочка» (при предоплате
  или реализации отсрочка не применяется), а если срок выпадает на нерабочий день —
  на ближайший следующий рабочий день.
  Ячейки сумм редактируются прямо в таблице без всплывающего окна: Enter — сохранить,
  Esc — отмена, пустое значение — очистить ячейку. Дата ячейки — срок оплаты; для
  ручного прихода программа рассчитывает дату поставки от этого срока по отсрочке
  поставщика, чтобы карточка поставщика и остальные таблицы показывали одну пару дат.
- **Карточки поставщиков:** условия оплаты и архив,
  история приходов с погашением по FIFO, статусы (оплачено/частично/просрочено/скоро срок),
  график баланса. В карточке можно задать отсрочку либо включить взаимоисключающие
  режимы **«Предоплата»** или **«Реализация»** — в этих двух случаях поле отсрочки
  неактивно и в сроках не используется. В верхней плашке и карточке поставщика кнопок
  «＋ Приход»/«＋ Оплата» нет. В карточке поставщика одна таблица:
  **Дата поставки · Срок оплаты · Сумма · Оплачено · Статус**.
  Условия правятся через кнопку **«Карточка поставщика»** в синей шапке или из карточки с историей.
- **Покупатели:** та же очищенная недельная таблица на всю ширину, что и «Поставщики»:
  покупатели строками, слева «Просрочено» и задолженность за неделю, на каждый день —
  «Приход» · «Долг» · «Оплата». Наименование и примечание покупателя (без УНП) по-прежнему
  добавляются и правятся кнопкой **«Карточка покупателя»** в шапке; отдельный учёт сумм
  покупателей пока не ведётся, поэтому числовые ячейки пустые.
- **Операции:** журнал с фильтрами и поиском, без кнопок редактирования/удаления в строках.
  Суммы добавляются и правятся прямо в ячейках «Поставщиков», а поставка — через
  всплывающую форму по клику на поставщика. У старых приходов, где разбивка была сохранена прежними версиями,
  в журнале по-прежнему видны сумма без НДС и НДС.
- **Данные:** импорт Excel (замена или добавление), экспорт обратно в тот же формат .xlsx
  (плюс лист «Операции» без потерь) и в CSV, резервные копии JSON
  (автоматически в папку `backups` при каждом сохранении + вручную), настройки и
  **ручной список праздничных дней**. Государственные праздники программа сама не
  подставляет: добавьте нужные даты в блоке «Праздничные дни».

## Где живут данные, флаги

По умолчанию: `%AppData%\Oplata\data.json`, рядом `oplata.log` и папка `backups`.

| Флаг (oplata.exe / console) | Значение |
|---|---|
| `-addr 127.0.0.1:8765` | Адрес сервера. Порт занят — возьмётся следующий свободный. `0.0.0.0:8765` — доступ по локальной сети (**без пароля!** — только в доверенной сети). |
| `-data <путь>` / переменная `OPLATA_DATA` | Другой файл данных. |
| `-portable` | Данные в `oplata-data.json` рядом с exe (удобно носить на флешке). Десктопный вариант подхватит этот файл сам, если он лежит рядом. |
| `-no-open` | Не открывать браузер автоматически. |
| `-no-seed` | Устарел и игнорируется (оставлен для старых ярлыков): стартовых данных в программе нет. |
| `-version` | Показать версию. |
