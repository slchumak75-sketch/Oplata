# Оплаты поставщикам (Oplata)

Windows-приложение на Go с HTML-интерфейсом для учёта оплат поставщикам — замена таблицы
[`Оплаты Строймаркет.xlsx`](Оплаты%20Строймаркет.xlsx).

**Термины — как в Excel:**

| Термин | Что значит |
|---|---|
| **Собств** | Сумма к оплате за поставленный товар (начисление). Дата записи — **срок оплаты с учётом отсрочки** (та же дата, что в шапке колонки Excel). |
| **Выплаты** | Фактически выплаченная сумма и дата выплаты. |
| **Задолженность** | Сумма всех «Собств» минус сумма всех выплат (столбец B в Excel). |
| **Просрочено** | Открытые (непогашенные) суммы, у которых срок оплаты уже прошёл. Выплаты погашают начисления по FIFO — сначала самые ранние по сроку. |

## Варианты программы (собираются автоматически на GitHub Actions)

| Файл | Вариант | Когда использовать |
|---|---|---|
| **oplata.exe** | Локальный сервер + интерфейс в окне Edge (режим приложения) или браузера по умолчанию | Основной вариант. Просто запустить, установка не нужна. |
| **oplata-desktop.exe** | Тот же интерфейс в отдельном окне Windows (Wails/WebView2) | Если удобнее «настоящее окно программы». Нужен WebView2 Runtime (в Windows 11 встроен). |
| **oplata-console.exe** | Как oplata.exe, но с консолью | Диагностика, серверный режим, запуск с флагами (`-addr`, `-data`, `-no-open`, `-portable`). |

Все три работают с **одним и тем же файлом данных** и одним интерфейсом.

**Где скачать готовый exe:** вкладка **Actions** → последний запуск CI → Artifacts
(`oplata-windows-amd64`, `oplata-desktop-amd64`), либо страница **Releases**
(релиз создаётся при пуше тега `v*`, см. [docs/BUILD.md](docs/BUILD.md)).

## Первый запуск

1. Запустите `oplata.exe`. Откроется окно интерфейса.
2. При первом запуске программа сама создаст файл данных
   `%AppData%\Oplata\data.json` и загрузит в него **стартовые данные из Excel за 2025 год**
   (43 поставщика; итог сверён с таблицей: задолженность **25 754,92**).
   Баннер в интерфейсе напомнит проверить одну запись с сомнительным знаком
   («Алваис», 11.03.2025 — в Excel выплата стоит с плюсом).
3. Если стартовые данные не нужны: вкладка **Данные** → «Очистить базу»
   (или запуск с флагом `-no-seed` до первого старта).
   Свои данные можно в любой момент заменить импортом другого Excel-файла.

> ⚠️ **Репозиторий публичный**, а исходный Excel и стартовые данные программы содержат
> реальные суммы оплат. Если это нежелательно — сделайте репозиторий приватным
> (Settings → General → Change visibility). Как собрать exe без встроенных данных — [docs/BUILD.md](docs/BUILD.md).

## Возможности

- **Сводка:** общая задолженность, просрочка, сроки на сегодня/неделю, обороты за месяц,
  таблица должников, списки просроченных и ближайших оплат, быстрая кнопка «Оплатить».
- **Таблица:** тот же вид, что в Excel (поставщики × дни месяца, пары «Собств»/«Выплаты»,
  строка «ВСЕГО», столбец задолженности). Клик по ячейке — операции этого дня.
- **Поставщики и карточки:** отсрочка платежа по умолчанию, архив, история начислений
  с погашением по FIFO, статусы (оплачено/частично/просрочено/скоро срок), график баланса.
- **Операции:** журнал с фильтрами и поиском. У начисления можно указать дату поставки и
  отсрочку — срок оплаты посчитается сам (и его можно поправить вручную), а также
  № накладной/счёта и комментарий.
- **Данные:** импорт Excel (замена или добавление), экспорт обратно в тот же формат .xlsx
  (плюс лист «Операции» без потерь) и в CSV, резервные копии JSON
  (автоматически в папку `backups` при каждом сохранении + вручную), настройки.

## Где живут данные, флаги

По умолчанию: `%AppData%\Oplata\data.json`, рядом `oplata.log` и папка `backups`.

| Флаг (oplata.exe / console) | Значение |
|---|---|
| `-addr 127.0.0.1:8765` | Адрес сервера. Порт занят — возьмётся следующий свободный. `0.0.0.0:8765` — доступ по локальной сети (**без пароля!** — только в доверенной сети). |
| `-data <путь>` / переменная `OPLATA_DATA` | Другой файл данных. |
| `-portable` | Данные в `oplata-data.json` рядом с exe (удобно носить на флешке). Десктопный вариант подхватит этот файл сам, если он лежит рядом. |
| `-no-open` | Не открывать браузер автоматически. |
| `-no-seed` | При первом запуске не загружать данные Excel 2025. |
| `-version` | Показать версию. |
